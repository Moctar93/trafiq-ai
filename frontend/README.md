# Frontend

The frontend provides the user interface of Trafiq AI.

It allows users to:

- Submit a website URL for analysis.
- Track audit progress.
- Visualize SEO scores and predictions.
- Explore machine learning insights.
- Download the generated audit report.

## Planned Technologies

- React
- TypeScript
- Tailwind CSS
- Chart.js
- Axios

The frontend communicates with the Django REST API to retrieve predictions and display SEO recommendations.
